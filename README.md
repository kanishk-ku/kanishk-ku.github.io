# Learn with Python Language with Explanation

GitHub Pages website assembled from the supplied ZIP archive.

## Publish
1. Create a public repository named `kanishk-ku.github.io` in the `kanishk-ku` account.
2. Upload the contents of this folder to the repository root. `index.html` must be at the root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for the deployment and visit https://kanishk-ku.github.io/.

## Contents
- `index.html`: homepage and course overview
- `lessons/`: six topic-based lesson pages assembled from supplied DOCX notes
- `downloads/`: supplied `.py` examples
- `course-materials/`: original archive contents, retained for reference
- `assets/`: styles and navigation script
